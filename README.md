# KAYOS: NoS demo 1

The Cold Open of **KAYOS: The Night of Silence**, playable in a phone or desktop browser.

**Play it:** https://smile88.github.io/KAYOS-NoS-demo-1/

Astra'Thalas, the two-thousandth Luminarae. You are Talindir, an old scribe of the Astral Archive,
at his desk late at night with a letter he has kept sealed for three hundred years. Explore the
Archive, take up the festival's Record, climb to the balcony — and be there when the Song stops.

About 25–35 minutes if you read things. Sound on.

## Controls

**Phone** (hold it sideways):

- **Left thumb:** walk. The stick appears wherever your thumb lands; push it to the rim to hurry.
- **Right thumb:** drag to look around. Pinch to zoom.
- **USE:** examine, talk, pick up. It lights up when there is something in reach.
- **Eye button:** first person. Stand at the balcony rail and look up at the Tower.
- In a conversation, tap the text to finish a line and tap a choice to choose it.

**Desktop:** WASD walk · Shift hurry · right-drag look · wheel zoom · F examine / talk · V first person.

Add `?fps=1` to the address to show a frame counter, or `?touch=1` to use the phone controls on a
desktop.

## What this is

A standalone slice of the main (private) project, carved out so it runs in a browser:

- Godot 4.7, **Compatibility (WebGL 2) renderer**, single-threaded web export, so it runs on GitHub
  Pages without special server headers.
- Phone controls in `godot/threed/coldopen/TouchControls.gd`.
- A light budget for the web (`ColdOpenWorld.apply_light_budget`): the web renderer draws a mesh
  again for every light that touches it, so only the lights near the camera stay on. That takes the
  opening shot from about 1,850 draw calls to under 300.
- The screen text stays at 1:1 pixels on phones (the pixel font breaks up when scaled down).
- The demo ends on its own card; tap to play again.

## Build it

Every push to `main` rebuilds the web version and publishes it to the `gh-pages` branch
(`.github/workflows/pages.yml`). To build locally with Godot 4.7 and its export templates installed:

```bash
godot --headless --path godot --import
godot --headless --path godot --export-release "Web" ../build/web/index.html
cd build/web && python3 -m http.server 8000     # then open http://localhost:8000
```

Tests (headless):

```bash
godot --headless --path godot res://tests/ColdOpenV2Test.tscn                    # plays the whole night
KAYOS_TOUCH=1 godot --headless --path godot res://tests/TouchControlsTest.tscn   # the phone controls
godot --path godot --rendering-driver opengl3 res://tests/PerfProbe.tscn         # where the draw calls go
```

`tools/touchtest.cjs` drives the exported build in a phone-sized Chromium with real touch events
(needs Playwright and the build served on port 8765).

The characters in `godot/assets/characters/lowpoly/` are generated by the main project's Blender
pipeline and committed here so the demo builds on its own.
